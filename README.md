# Teluk Cerah — Kota Terbuka

**Teluk Cerah** is an original 2D top-down open-world crime game set in a bright
modern coastal city. You are Rani, a courier from Teluk Cerah, taking jobs from
Dimas, a local fixer. Walk the streets, steal and drive cars, dodge traffic and
pedestrians, and outrun the police as your wanted stars rise.

## Missions

1. **Paket Kilat** — pick up a package at Pasar Pagi and deliver it to Dermaga Teluk.
2. **Tarik Mobil** — steal the gold car at Parkir Mall and bring it to Bengkel Roda.
3. **Jalan Keluar** — escape a three-star police chase and reach the Rumah Aman safe house.

## Features

- Open city: road grid, buildings, sidewalks, beach, bay and a wooden pier
- Driveable cars, traffic, and pedestrians who react to crime
- Wanted stars, police car chases, ramming, and arrests
- Combat on foot, health, cash, and a live minimap with player, police, and mission markers
- Start screen, pause, save (localStorage), game-over screen, and synthesized WebAudio sound
- All art drawn in code — no external images, no network requests, no Rockstar assets or names

## Controls

| Key | Action |
| --- | --- |
| WASD / Arrow keys | Walk / drive |
| E | Enter or exit a car, pick up and deliver |
| F / Space | Punch |
| P | Pause |
| M | Mute |
| R | Restart after game over |

## Run it

```sh
node serve.ts
```
